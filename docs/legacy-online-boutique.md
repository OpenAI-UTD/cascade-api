# Legacy Online Boutique Target

`targets/online-boutique-src/` is retained as an **empty, fetch-on-demand**
placeholder for the legacy upstream source. Cascade's canonical target workload
is Sock Shop under `targets/sock-shop/`.

The directory previously held a gitlink snapshot with no `.gitmodules` entry,
so fresh clones got an empty directory. It now contains only a `README.md`
with manual fetch instructions; the source is not tracked here.

Do not use Online Boutique for current demos, default policies, or acceptance
scripts. It may be useful only for historical comparison or deliberate legacy
compatibility testing.
